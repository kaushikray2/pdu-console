PDU connection

Where this console reaches this PDU's management card, and the login it uses. Changes are tested against the PDU first — nothing is saved unless the new settings connect. The console refuses any address on the blocked list (Console settings).

Outlet names

Names are written to the PDU itself (max 23 characters) — they show on the PDU's own pages too. A rename keeps the outlet's power delays and reboot duration exactly as they are.

Refresh interval

How often this console polls this PDU in the background.

Remove this PDU

Console settings

Shared by the whole console, not tied to one PDU.

Blocked addresses

The console will refuse to connect to these IP addresses or hostnames, for any PDU — use it for units this console must never touch (for example a production PDU).

Safety

The console only ever contacts the PDUs it manages, and refuses any address on the blocked list as a connection target. Any outlet or group you lock with its 🔒 button needs the console password before it can be switched or unlocked.

Console password

This password signs you in and unlocks locked outlets and groups on every PDU. Changing it signs out other sessions.
